# DX4GREY Portfolio

Responsive portfolio for DX4GREY, inspired by the supplied visual reference.

## Included
- Responsive desktop / tablet / mobile layout
- Refined GitHub profile card based on the public DX4GREY profile
- Mobile right-side navigation drawer with backdrop
- Escape / close / link navigation support
- Scroll locking while the drawer is open
- Reduced-motion support
- Pointer-aware custom cursor and project hover effects
- Static HTML/CSS/JS — no build step required

## Run
Open `index.html` in a modern browser.
